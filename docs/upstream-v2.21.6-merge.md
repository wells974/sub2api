## 合并取舍与修复

- 合入上游请求代理池、搜索续轮和安全诊断、TOTP 因子绑定与恢复、Free UltraFast 等改动。保留二开的 BPS 自动授权、手动授权入口、一次 Schema 纠错、按需工具目录、图片策略、推理强度、错误脱敏、缓存计费、号池通知和自定义更新支持。
- 搜索中的本地工具校验失败继续通过类型化错误传递，保留 `bridge_tool_validation`、`search_no_repair` 和字段诊断，不误记为上游账号故障。其余搜索失败使用上游安全诊断。公开 neutral/legacy 两种模式分别验证，内部诊断不依赖公开错误码。
- 接受上游独立的纠错请求体，保留二开纠错响应校验和原始请求计费元数据；搜索请求继续不纠错、不重放、不切号。
- 采用上游请求级代理租约。新增真实本地 HTTP 代理测试，覆盖 JSON/SSE 下的 Schema 纠错，以及直接搜索、原生历史续轮、工具目录披露，共享同一出口。
- BPS 首次自动授权复用普通 2FA 的单代理导入约束：新建时选择单代理模式，导入完成后可编辑为请求多代理。前端同时保留 BPS OAuth client 校验与代理配置校验，避免只应用其中一方。
- Excel 授权适配器同时兼容旧版固定登录程序和新增 TOTP 因子绑定补丁，修复新版中不存在 `generatedFromSecret` 的运行时错误。保留绑定因子选择，并在异步请求头准备完成后即时生成验证码，减少跨窗口失效。
- TOTP 因子缺失、绑定缺失或密钥缺失使用安全的交互失败分类。配套运行包加入真实固定版本登录程序的 BPS 回归，包括多因子、绑定因子、缺失及歧义场景。
- 日历回归改用已有历史重复午夜日期，避免未来夏令时规则变化使测试失效；业务日期处理逻辑未改动。
