# v2.24.2.2 发布说明

本版基于上游 v2.24.2，包含生产分支修复提交 `bae16d661`。

- 网关模型目录现在会展开通配白名单可匹配的平台模型，同时保留显式配置的私有模型。目录沿用账号和分组的准入规则。
- 网关白名单由管理员手动更新。OAuth 新建账号的首次同步与列表轮询共用同步记录，重复的创建回调只触发一次同步。
- BPS 客户端只回传 ToolSearch 结果时，可以从同一会话恢复对应的搜索调用和工具目录，继续按续轮规则纠错。遇到缺少原调用的显式客户端结果时，会提示补发完整历史。
- HTTP 桥接续轮按调用标识识别上游重复返回的同一工具调用，保留对应的工具结果。

已在 PostgreSQL 核对同一请求重放和同用户并发结算。四组测试中，重放新增扣费均为零，两笔有效请求的扣费之和均与余额变动一致。
