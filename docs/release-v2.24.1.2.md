# v2.24.1.2 发布说明

本版基于上游 v2.24.1，包含生产分支修复提交 `1534f8873`。

- 号池通知保留最新的状态基线。多实例使用旧配置刷新时，同一轮号池变化只产生一次通知。
- 单账号静音会取消该账号排队中的低余额告警。解除静音后，新信号可以再次触发通知；周配额和号池通知继续按各自设置投递。
- BPS 能识别原生 ToolSearch 的后续请求。客户端下一轮省略搜索工具时，已经返回的工具定义仍可使用。未收到工具结果的调用会等待结果，避免误触发纠错。
- 新建 OAuth 账号后的模型同步按账号只执行一次，延迟或重复到达的创建回调共用同一次同步。定时刷新和管理员手动重试仍可用。

已用同一条包含纠错的请求核对缓存计费。八种组合均产生一条用量记录、一次扣款，实扣与复算一致。BPS 自动和手动授权已通过离线回归。
