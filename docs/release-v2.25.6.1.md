# v2.25.6.1 发布说明

本版基于上游 v2.25.6，包含生产分支复查修复 `88847c84f`。

- 普通 OpenAI OAuth 和 2FA 账号可在授权页勾选「创建后同步上游支持的模型」。新建账号的首次同步与轮询共用同步记录。独立 BPS OAuth 使用上游授权流程。
- 分组兜底配置可独立加载和保存，沿用上游 SLA 排除规则。单账号低余额静音期间，号池和周配额通知仍正常排队。
- Jev 代理列表读取失败时，管理员仍可保存其他设置，已配置的代理和密钥会保留。
- 请求体截断、超限或读取失败时，大小记录为未知。旧诊断表已移除时，重复执行迁移会保留已有测量值。
- OAuth 429 统计按数据库时钟核对账号或路由切换时间，避免旧请求进入新一轮统计。
